# Glosario de la interfaz en español (DSB)

Traducción de la UI (`src/translations/es.ts`, `src/translations/es-oscd.ts`). El idioma por defecto es español; se puede cambiar en Configuración.
Los plugins externos (Publisher, Communication Explorer, TransnetBW, etc.) son bundles separados y siguen en inglés.

| Inglés (IEC 61850) | Español usado | Nota |
|---|---|---|
| Bay | Campo (Bay) | A validar: también "Celda" / "Bahía" |
| Voltage level | Nivel de tensión | |
| Substation | Subestación | |
| Logical device / node | Dispositivo lógico / Nodo lógico | |
| Data set / Data attribute / Data object | DataSet / Atributo de datos / Objeto de datos | |
| Report control | Bloque de control de reportes | |
| Sampled values | Valores muestreados (SMV) | |
| Subscriber / Publisher | Suscriptor / Publicador | |
| Single line diagram | Diagrama unifilar | |
| Late binding | Enlace tardío | |

Los términos del estándar (GOOSE, MMS, SCL, ExtRef, LGOS, ConnectedAP, DAI, etc.) se dejan sin traducir.
